# 🏋️‍♂️ Health and Fitness Data Analysis

An **end-to-end data analysis project** focused on extracting insights from diverse health and fitness datasets.  
The project leverages **Python (Pandas, SQL)** for preprocessing and querying, and **Power BI** for designing interactive dashboards to deliver actionable insights.

---

## 🚀 Features

- 📊 **Data Preprocessing with Pandas**  
  - Cleaned, transformed, and analyzed **18 diverse health-related CSV files**.  
  - Handled missing values, datatype inconsistencies, and applied normalization techniques.

- ⚡ **SQL Optimization**  
  - Designed and optimized queries for efficient filtering and transformations.  
  - Processed **~150k+ records** while resolving **datatype compatibility issues**.  

- 📈 **Power BI Dashboards**  
  - Built **6+ interactive dashboards** with drill-downs, slicers, and KPIs.  
  - Delivered **5+ actionable, data-driven insights** to support decision-making in marketing and strategy.
